# support-page

Static support page for a personal project.

## Stack
- Static HTML (no build step)
- GitHub Pages (hosting)
- GitHub Actions (CI/CD)
- Cloudflare (DNS only)
- Let's Encrypt (TLS via GitHub Pages)

## Deployment
Push to `main` → GitHub Actions deploys to GitHub Pages.

## Local preview
Open `index.html` in a browser. No build required.
